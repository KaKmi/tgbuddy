# TgBuddy Agent Team v3

## 设计目标

- 保留纸白/暖炭灰双主题与原三栏结构，不增加常驻第四栏。
- 中间对话区只表达主管 Agent 的叙事、关键委派、阻塞和授权。
- 右侧工作台在“成果”和“团队”之间切换；团队内部提供任务、成员、授权三个视图。
- 任务失败可以查看成员详情、原成员重试或携带摘要重派。
- 多个权限请求合并进入队列，但仅允许批量处理风险级别接近的请求。

## 动效来源与规则

- 参考原桌面应用中侧栏宽度、弹层、任务进度和折叠块的真实 transition 节奏。
- 面板切换约 200–300ms，内容进入约 150–200ms，进度条约 500ms。
- 动效只解释层级、状态和归属变化，不使用无意义持续动画。
- 遵循 `prefers-reduced-motion`，用户关闭动画时立即完成状态变化。

## 可操作路径

- 成果 / 团队工作台切换
- 任务 / 成员 / 授权切换
- 点击任务或成员进入 Agent 详情
- 审查 Agent 失败后重派
- 单项或批量允许授权请求
- Team 模板、权限模式、共享技能和连接器菜单
- 上下文用量面板
- 纸白 / 暖炭灰主题切换并持久化
