# TgBuddy Codex Light v2

## 设计假设

- 默认采用偏暖的纸白色，而不是刺眼纯白；深色主题使用暖炭灰而不是纯黑。
- 保留旧原型的三栏结构：会话、Agent 过程、结果区。
- 结果区负责产物预览，对话区主要表达过程和决策。
- 双主题切换会写入 `localStorage`，刷新后保留。

## 设计来源

- 原交互原型：`tgbuddy-mockup/TgBuddy 交互原型.dc.html`
- 当前客户端：`src/renderer/`
- 视觉方向：参考 Codex 桌面端的明亮、中性、低装饰密度，但没有复制其品牌资产。

## 本版补全

- 工作区切换与会话搜索
- 对话顶部状态与结果区开关
- 模式、专家、技能、连接器、模型和上下文入口
- 上下文用量及压缩信息
- 权限请求和常驻规则展示
- 产物筛选、只读预览、打开与让 Agent 修改
- 工具、MCP、技能与外观设置页
- 明亮/深色主题切换
