### 3.3 M1 · 可恢复 Agent 内核

M1 已形成可恢复、可停止、可持久化、可执行工具和可压缩上下文的 Agent Harness 基座：

- App catalog 与 pi Session backend 共用同一 SQLite 文件、独立 schema；
- Session catalog、消息回放和 legacy JSONL 幂等导入进入生产 Composition Root；
- Runtime 支持同 Session 单飞、跨 Session 并行、主动停止和启动恢复；
- pi `AgentHarness` 的 thinking、text、error、message_end 和工具事件进入统一事件链；
- 手动压缩、85% 自动压缩、3 秒延迟、输入排队和取消恢复进入 Runtime；
- 编辑并重发与扁平派生会话在重启后保持一致；
- Session、Run、Context 的 canonical owner 已收口到 Runtime、SQLite adapter 与 `kernel/pi`；
- 旧 Session、orchestrator、compaction 和 `src/kernel/*.ts` 适配 owner 已删除。

### 3.4 Agent Runtime 正式门面

R01–R02 在不改变 Renderer、Preload 和 IPC wire 的前提下完成运行时语义收口：

- 正式门面统一为 `AgentRuntime`，事件统一为 `AgentRuntimeEvent*`；
- Electron Composition Root 通过 `TgBuddyApplication.agentRuntime` 持有唯一 Runtime；
- 用户动作保留 `agent.send()` / `agent:send`，Main IPC 将其翻译为 `agentRuntime.runs.start()`；
- Runtime 内部使用 `StartRunInput` 与 `RunCoordinator.start()`，内核继续通过 `AgentEngine.run()` 执行；
- `AgentHarness` 仍只存在于 `src/kernel/pi/**`，Runtime 不依赖 pi、Electron 或具体存储。

关键提交：

- `10a5c5f refactor(runtime): establish AgentRuntime facade`
- `refactor(runtime): clarify run start semantics`（R02 本 Slice）

### 3.5 M3 · 通用能力系统（C01–C12）

M3 已形成 Channel / Profile / Tool / Skill / MCP 全链路能力系统：

- SecretStore（safeStorage 加密 blob）只存 ref，SQLite 渠道表无明文；一次性迁移 legacy channels.json；
- 渠道 CRUD 与设置页、连通性测试与模型发现（OpenAI 兼容 `/models`）、Profile 预设与输入区模型选择（Run 启动固化不可变快照）；
- 统一 ToolRegistry：内置工具与 MCP `server.method` 工具注册；权限收敛为「权限模式（默认/计划/完全访问）+ 总是允许规则 + 内置分类兜底」三层，工具页只读展示（per-tool 三档已移除，破坏性命令仍为硬约束）；
- Skill manifest 发现（内置/用户级/工作区，随工作区刷新）与正文按调用加载（越界引用拒绝）；
- MCP stdio/http 连接/断开/重连/状态卡、工具发现与真实调用（断线不伪造成功）；
- 每个 Run 持久化 CapabilitySnapshot（Profile/模型/工具/Skill/MCP）与分类 token/cost 账本；
- Main 遗留 channel/tools owner 与 checker 豁免清零。

M3 后的权限模型收口（用户方向，`c531488`）：

- 对照 Proma 与 pi 原生能力，删除 per-tool 三档设置：工具页只读展示内置分类默认，
  完全访问（bypass）= 全部放行，默认权限 = 读放行/写与命令询问，计划模式 = 只读调研；
- 计划模式 skill 化：新增内置 `plan-mode` 技能承载完整规划工作流，`enter_plan_mode` 工具移除，
  `exit_plan_mode` 收缩为宿主只读能力始终注入；进入由模式 chip 显式切换（Codex 显式模态）；
- 审批卡 Codex 化：TL;DR 摘要 + 展开完整计划 + 拒绝意见。
